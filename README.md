 Videojuego Paint - Modificación

Este repositorio contiene el código modificado del videojuego Paint, originalmente desarrollado por Grant Jenks como parte de la librería free games. Este proyecto se realizó como una actividad colaborativa en parejas, aplicando control de versiones git.

 Descripción de la Actividad

El objetivo principal fue analizar, documentar y extender la funcionalidad del código original de Paint. Para ello, el trabajo se dividió de la siguiente manera:

Estudiante 1:
 Creación y configuración inicial del repositorio.
 Adición de un color nuevo a la paleta de opciones.
 Implementación de la funcionalidad para dibujar un círculo.

Estudiante 2 :
 Completar la lógica para dibujar un rectángulo.
 Completar la lógica para dibujar un triángulo.

Ambos integrantes colaboraron en la documentación del código y en mantener un flujo de trabajo coordinado mediante commits, pushes y pulls.

 Nuevas Funcionalidades

Las teclas de control se han actualizado para incluir las nuevas figuras y colores:
 `(Letra del nuevo color)`: Cambia el color del trazo al nuevo color añadido.
 `c`: Selecciona la herramienta para dibujar un círculo.
 `r`: Selecciona la herramienta para dibujar un Rectángulo.
 `t`: Selecciona la herramienta para dibujar un Triángulo.
